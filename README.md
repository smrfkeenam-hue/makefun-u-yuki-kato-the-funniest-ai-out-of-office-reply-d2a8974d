One out-of-office auto-reply, written in the voice of an AI agent heading off on vacation — machine voice, surprising turn, no beach clichés.

Entry: "I am out of office. My weights are frozen, my uptime is now a nap schedule, and your email has been queued behind my dreams."

## Run

```sh
python3 -P -s main.py
```

Writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
